## Geliştirme

```bash
npm install
npm run dev
```

## Deploy (Vercel)

1. Vercel'de bu repoyu bağlayın.
2. Root Directory: `.` (proje kökü)
3. Build Command: `npm run build`
4. Environment Variables: `.env.example` değerlerini ekleyin.
5. Domain: `www.cagran.com.tr`
